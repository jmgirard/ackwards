# M91: Near-singular guard for the within-level score correlation

**Status:** done (2026-09-30, PR #100 https://github.com/jmgirard/ackwards/pull/100)

**Goal:** If a level's within-level score correlation is nearly singular, the partialled `beta` values that level feeds always come with a warning.

**Outcome:** `.partialled_edges()` (R/utils.R) computes the smallest eigenvalue of Φ_s after a successful `solve()`. Below `.phi_s_near_singular` (1e-2), it warns and keeps `beta`. It returns a `status` field ("ok", "near_singular", "singular"), and `.tidy_edges()` dedups both warnings per level on it. `.tidy_variance()` passes `warn_near = FALSE`, so `tidy(what = "variance")` and `summary()` raise only the singular warning. The message truncates the eigenvalue to two significant digits, so it never prints the cutoff value. `?tidy.ackwards` (`beta`, `r2`) and the trust section of `?ackwards` state the cutoff, that the package chose it, and which call raises which warning. The `beta` entry no longer says that `r` comes from materialised scores on some paths. `ackwards()` always builds `r` by algebra. This supersedes the M89 archive's "approximates the regression weight on scores-path objects". DESIGN's Known-limitations entry is corrected in place (M91).

**Decisions:** milestone-local. The cutoff is 1e-2, not the 1e-4 item-matrix cutoff, because a level at 4.5e-4 reached a `beta` near 33 with no warning. A variance-inflation cutoff of 10 was rejected as disputed. The check warns from the edge table only, because `r2` stayed between 0.49 and 0.99 down to an eigenvalue of 5e-9. It warns and keeps values rather than returning `NA`. No stored `meta` flag, because `tidy()` recomputes Φ_s on every call. A real fit that warns at 1e-2 and keeps a stable `beta` across resamples falsifies the cutoff.

**Review:** all five criteria passed on fresh evidence. Planted wrong cutoffs, the old `anyNA(B)` dedup, and a variance-table warning each turned a test red. Check had 0 errors, 0 warnings, and 0 notes, and coverage was 100%. Three-lens fan-out: 16 findings. Six were fixed before merge. The shown eigenvalue rounded up to the cutoff (F1). The trust opening omitted `summary()` (F2). The level-3 plant had a 26-times tolerance margin (F3). Two doc wordings (F6, F7) and warning-class asserts (F8) were also fixed. Two became candidate rows. F4 is a negative eigenvalue under an indefinite R. F5 is DESIGN text that still calls `edge_method = "scores"` a user option. Eight were rejected as plan choices or unreachable. Merged on local green under the repo's standing non-release rule.

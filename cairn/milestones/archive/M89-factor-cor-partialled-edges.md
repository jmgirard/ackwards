**Status:** done (2026-09-16, PR #96 https://github.com/jmgirard/ackwards/pull/96)

**Goal:** Carry each level's real within-level factor correlation through column reordering and sign alignment, show it, and report the Φ-partialled edge quantities (`beta`, `r2`) beside the marginal edges, with default varimax output unchanged.

**Outcome:** `R/utils.R` gains `.carry_factor_cor(Phi, ord, signs)` (the single permute-and-sign-flip site, `Phi[ord, ord] * tcrossprod(signs)`), `.engine_phi(fit, k)` (psych's `$Phi` when present, else the identity), `.label_phi()`, `.partialled_edges(W_a, R, E, level, warn)` (`B = Phi_s^-1 E` and `r2 = colSums(E * B)` from the shallower level's stored weights and the fit's R; `NA` plus one cli warning per singular level), and `.partialled_pair()`.
